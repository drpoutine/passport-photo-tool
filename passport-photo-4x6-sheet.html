Offline setup — optional

The first run needs the internet to fetch the engine (~10 MB) and model (~450 KB). To make it work with no connection at all, save these four files once, then load them here:

  • vision_bundle.mjs
  • vision_wasm_internal.js
  • vision_wasm_internal.wasm
  • selfie_segmenter.tflite

Head-height figures follow the published requirements for each document, but authorities do change them — check the current rules with the issuing office before you pay for prints. This tool crops and lays out; it does not judge background colour, lighting, expression, or glasses, which cause just as many rejections.
